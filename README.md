# Utility Hub

Utility Hub is a Windows desktop application built with Python and PySide6. It brings useful desktop tools, system information, and Python script management together in one interface.

**Current release: v0.4.5**

## Features

- **Desktop interface:** A centralized launcher with navigation for Home, System, Applications, Scripts, Cybersecurity, My Projects, Notes, and Settings.
- **System information:** View an overview of your computer and system resources.
- **Script library:** Browse Python scripts and folders through a file-explorer-style interface.
- **External script folders:** Register additional folders on your computer to make supported Python scripts available in the library.
- **Script execution:** Launch Python scripts directly from Utility Hub.
- **Script output console:** View script output and errors in the application.
- **Script controls:** Monitor execution and stop a running script.
- **Desktop notifications:** Receive notifications when scripts start and when execution finishes or fails.
- **Custom styling:** A dark desktop interface designed to keep tools accessible from one place.

Some navigation sections may still be under development.

## Requirements

- Windows
- Python 3.14 or another compatible Python version
- Git, if cloning the repository
- PySide6
