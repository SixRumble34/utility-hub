# Utility Hub

Utility Hub is a Windows desktop application built with Python and PySide6. It provides a central workspace for system information, applications, scripts, cybersecurity tools, projects, and notes.

## Current Release

**Version:** 0.2.0  
**Release focus:** Live System Monitoring  
**Platform:** Windows  
**Language:** Python  
**GUI Framework:** PySide6

## Features

### Home
- Central workspace with quick-access navigation.
- Shortcuts to the application's main sections.

### System Monitoring
- Live CPU usage percentage and progress bar.
- Live memory usage percentage and progress bar.
- Disk usage percentage and progress bar.
- System uptime, updated automatically.
- Computer name and operating system information.
- OS version, processor information, and logical CPU core count.
- System architecture and Python version.
- Used and total memory and disk capacity.
- Automatic refresh at one-second intervals.
- Manual refresh button.

### Applications
The Applications section is reserved for future application-launching functionality.

### Scripts
The Scripts section is reserved for future script-management and automation functionality.

### Cybersecurity
A planned workspace for cybersecurity tools and lab shortcuts.

### My Projects
A planned space for organizing development projects.

### Notes
A planned space for personal notes and quick references.

### Settings
A placeholder for future application preferences and customization.

## Requirements

- Windows 10 or Windows 11
- Python
- PySide6
- psutil
