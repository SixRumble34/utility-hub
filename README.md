# Utility Hub

Utility Hub is a personal desktop dashboard built with Python and PySide6.

The goal is to provide a centralized place to access desktop utilities, system information, applications, scripts, cybersecurity tools, projects, and notes.

## Current Features

- Dark-themed desktop interface
- Sidebar navigation
- Home dashboard
- Quick Access section
- Dedicated sections for system information, applications, scripts, cybersecurity, projects, notes, and settings

Some sections are currently placeholders and will gain functionality in future releases.

## Requirements

- Python 3.14 or another compatible Python version
- PySide6
